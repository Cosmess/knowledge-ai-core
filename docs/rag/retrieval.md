# Retrieval

Retrieval must support:

- semantic search
- keyword search
- hybrid search
- filters by domain
- filters by audience
- filters by system
- filters by space
- filters by document type
- filters by updated date and version

MVP:

```txt
PostgreSQL + pgvector similarity search
```

Later:

```txt
hybrid search with text ranking + vector score
reranking
semantic cache
```
